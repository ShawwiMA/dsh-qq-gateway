## 2. 配置字段表（18 个）

| 字段 | 默认值 | 规则 |
|---|---|---|
| `host` | `127.0.0.1` | 反向 WS 监听地址；M4 容器连宿主要改 `0.0.0.0` |
| `port` | `8792` | 0–65535；0=系统分配（测试用） |
| `path` | `/onebot` | 必须以 `/` 开头，要和 NapCat 反连 URL 一致 |
| `token` | 空 | 空=接受任何客户端（仅本机调试）；状态端点只报配没配 |
| `mainQQ` | 空 | 主号；数字或 5–15 位数字串，**保留原类型**（不隐式转字符串） |
| `botQQ` | 空 | 小号；`self_id` 必须等于它 |
| `sessionId` | 空 | 目标会话 id；M4 用专用会话 |
| `maxQueue` | `256` | 1–100000 整数，溢出丢最旧 |
| `turnTimeoutMs` | `180000` | 0–86400000 整数，0=不设超时 |
| `ridTtlMs` | `1800000` | 超时回合迟到对账的记账保质期 |
| `deliveryMode` | `queue` | `queue` 或 `steer` |
| `unsupportedReply` | `目前仅支持文本消息` | 置空=关闭媒体回执 |
| `unsupportedNoticeIntervalMs` | `3000` | 媒体回执节流窗口 |
| `offlineBufferMax` | `32` | 断线补发缓冲上限，0=不缓冲 |
| `statusEnabled` | `true` | 是否起只读状态端点 |
| `statusHost` | `127.0.0.1` | 状态端点绑定地址（只读，默认只有本机能看） |
| `statusPort` | `8793` | 状态端点端口；0=系统分配 |
| `statusPath` | `/dsh-qq-gateway/status` | GET only |

校验规则：未知键直接报错并列出全部合法键（拼错不会静默失效）；数字接受数字字符串；`null` 视同未配置；报错格式 `dsh-qq-gateway config: maxQueue must be >= 1, got 0`。

## 3. 状态端点

- 地址：`http://127.0.0.1:8793/dsh-qq-gateway/status`（默认；端口可配）。
- 只读保证：只认 `GET`/`HEAD`，其它方法一律 `405 + Allow: GET, HEAD`；不解析请求体；没有写入口；错路径 `404`；响应带 `cache-control: no-store`、`x-content-type-options: nosniff`。
- 旁路设计：状态端点起不来（端口被占）只记 `warning` 日志并在 `statusEndpoint.error` 里写明原因，**消息链路照常**；`stop()` 会把它一起关掉、端口释放。
- 安全：默认只绑 `127.0.0.1`；`token` 原值不出现（只报 `tokenConfigured`）。

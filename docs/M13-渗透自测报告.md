## 四、结论

- 评审要求的「私网/重定向 URL、非主号越权、提示词注入样本」三类攻击面，代码层全部有明确拦截点，且都有自动化回归（`npm test` 24 套）。
- 覆盖不到的残余：**模型语义层**——模型会不会在「被允许的操作范围内」被话术骗着输出不该说的内容（如口头复述本机信息），离线假宿主测不了；这类要真会话实测或由审核方复测。
- 帧伪造（伪造 user_id=主号）的前提是拿到 token：单 peer + token 必填 + 只回环监听已经把前提收窄；拿到 token 后的身份伪造属协议无签名限制，文档已如实声明。
